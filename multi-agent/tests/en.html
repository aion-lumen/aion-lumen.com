2. Ledger as a complete path

On 22 September, Qwen 3.8 passed 28 of 30 Ledger question-planning cases after adjustments. A separate integration test passed 18 of 18 cases and included nine actual model calls; another 28 calculation checks ran without a model.

These results measure different layers and are not combined into a single accuracy figure. Retested cases after changes are not independent evidence for unseen phrasing.

3. Why there is no overall winner

Earlier mail tests used 40 synthetic messages. Some candidates produced empty or unparseable answers; these protocol failures do not reliably measure their subject-matter ability. Knowledge selection and today’s mail configuration come from additional, separate experiments.

Conclusion: The current lineup remains a working configuration. Gemma 4 26B is a promising candidate for short triage tasks; changing a role requires retesting the same workload, including edge cases and tool calls.
